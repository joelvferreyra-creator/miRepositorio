# Misión 2

Procesador de textos gratuito para estudiantes, sin registro ni correo electrónico.

## Funciones

- Editor de texto enriquecido.
- Guardado local automático mediante `localStorage`.
- Importación de plantillas `.docx` y `.odt`.
- Exportación de documentos a PDF.
- Diseño adaptable para computadoras, tablets y celulares.
- Los archivos no se envían a ningún servidor.

## Uso

Abre `index.html` en un navegador moderno o publica el repositorio con GitHub Pages. Pulsa **Subir plantilla** para abrir un archivo Word u ODT y **Descargar PDF** para obtener la entrega final.

> La conversión de documentos complejos puede tener diferencias en tablas, fuentes, imágenes o saltos de página. Conviene revisar el documento antes de descargarlo.

## GitHub Pages

En el repositorio, entra en **Settings → Pages**, selecciona **Deploy from a branch**, elige `master` y la carpeta `/ (root)`, y guarda. La URL será:

`https://joelvferreyra-creator.github.io/miRepositorio/`

La aplicación es estática y no necesita backend ni cuentas de usuario.
